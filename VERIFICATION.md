# PixelTrace 1.0.0 verification

Release target: Windows x64. The application and repository release version is **1.0.0**, with assembly/file version **1.0.0.0**. The Windows application manifest uses the same four-part version. This release consolidates the completed application into a single standalone distribution.

## Stack and build

- .NET 10, Avalonia 12.1.3, Insiyab.Avalonia 0.3.2, OpenCvSharp 4.13.0.20260627 and OpenCV 4.13.0.
- Built using .NET SDK 11.0.100 targeting .NET 10, the 10.0.15 Native AOT compiler and Visual Studio 2026 C++ tools.
- The `WindowsNative` publish profile sets `SelfContained=true`, `PublishAot=true` and `OptimizationPreference=Size`. Runtime code is included in the executable; a .NET installation is not required.
- Native vendor PDBs, FFmpeg, video/ML modules and separate CoreCLR/ReadyToRun files are excluded.
- ZIP and 7z contain the same files: about 46 MiB extracted, about 19 MiB ZIP or 13 MiB 7z. Exact sizes and SHA-256 hashes are generated by the publish script.

## Native runtime

`tools/Build-NativeOpenCv.ps1` verifies the upstream source archive hashes before compiling unmodified OpenCV 4.13.0 and OpenCvSharp commit `b161e7e012f5101f6d5dc68a835c59db6cc88b18`. Only core, imgproc and imgcodecs are enabled, with JPEG, PNG, TIFF, WebP and BMP support.

The tested OpenCvSharpExtern DLL is 5.54 MiB, SHA-256 `F29C0DDF9F7944C817BD0E6922AE32BFF61F579D566ED39C0A1A19976C2C5F19`. PE dependency inspection lists KERNEL32.dll and ole32.dll. The native library uses a static C runtime and has no Media Foundation dependency. IPP, OpenCL and extra CPU-dispatch variants are disabled, prioritizing package size over optional acceleration. Sources and binary identity are recorded in the package's `native-build.json`.

## Automated validation

The solution has **59 passing tests: 48 core and 11 Avalonia/Skia UI workflow cases**. Tests use the exact reduced native DLL distributed with the application. They cover:

- Invalid/corrupt/missing inputs, header size guards, five image formats, small images, 16-bit/alpha handling and Unicode paths.
- All eight EXIF orientations, TIFF orientation, partial blocks, noise/frequency responses, normalization, masks and combined scores.
- Immutable rendering, full-resolution PNG dimensions and pixels, source overwrite protection and cancellation.
- Review-region grouping/ranking/attribution, fixed thresholds, limited coverage and oriented region bounds.
- FileUpload/dialog submission, locked-source reanalysis, Cancel rollback, result selection, cached display changes and image replacement.
- Arabic layout and library translations, theme switching, one image canvas, summary navigation and momentary original comparison without losing zoom.
- Safe closure during analysis/rendering and disposal of native image resources.

## Windows execution

The compact executable is checked through real Windows UI Automation and native Open/Save dialogs using `tools/Smoke-Desktop.ps1`. Checks include analysis, result switching, locked reanalysis/Cancel, display defaults, zoom, full-resolution PNG export and an unchanged source SHA-256. Arabic/dark mode and unmirrored image content are checked as well. Normal shutdown must return exit code 0, with empty stderr and no crash log.

Standalone validation starts the executable with invalid .NET runtime paths and runtime roll-forward disabled, verifies that its window opens and no external CoreCLR/hostfxr module is loaded, then closes it normally. The AOT-compatible Analyze button uses a property-change subscription instead of a reflection binding, and detaches the subscription when its dialog closes.

Release evidence is stored locally under `artifacts/verification/v1.0.0`. The older size experiments under `artifacts/size-audit` are not distributed. Archive integrity and published asset digests are checked before the release is made public.

## Limits

These checks validate application behavior and localization, not forensic accuracy on a real-photo benchmark. No manipulation or AI-generation probabilities are claimed. Linux/macOS execution, unusual codec variants, exhaustive hardware performance and sustained use at the 40 MP safety limit are not verified. Native codec calls complete before cancellation can take effect.

Documentation, comments and release notes are English. Arabic remains in UI localization and localization/Unicode tests. The project is MIT licensed; upstream licenses and font notices are retained in the distribution.
