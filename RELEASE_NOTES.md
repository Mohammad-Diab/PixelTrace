# PixelTrace v1.0.0

Offline digital image forensics for Windows x64.

## Features

- Noise, frequency, JPEG compression, texture/edge and ELA analysis, with a combined overlay.
- JPEG, PNG, BMP, TIFF and WebP input, plus full-resolution PNG export.
- A single image viewer with zoom, pan, a color guide and **Show original** comparison.
- Analysis summaries with clickable regions to inspect.
- Arabic and English interfaces with light and dark themes.
- Local processing without uploading your images.

## Run

Download the 7z archive from Assets, extract it completely and open `PixelTrace.exe`. Keep the extracted files together. No .NET installation is required.

Analysis highlights differences for inspection; it does not certify authenticity.
